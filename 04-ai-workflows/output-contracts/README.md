# AI 出力フォーマット（出力契約）

各 AI タスクで要求する標準的な出力構造です。プロンプト内では、必ず対応する `output-contract` を参照してください。

## 要件ドキュメント出力

```markdown
# （プロジェクト名）要件ドキュメント

## 一、システム概要
## 二、ユーザーの役割
## 三、機能モジュール
## 四、データモデル
## 五、既存システムとの関係
## 六、OA との連携
## 七、技術方針
## 八、開発フェーズ
## 九、開発方法
## 十、多人数協業

## 未決事項
- [ ] ...
```

## API 設計出力

```markdown
# API 設計

## API 一覧
| メソッド | パス | 用途 | 権限 |

## API 詳細
### POST /api/v1/xxx
**リクエスト：** ...
**レスポンス：** ...
**権限：** ...
**境界ケース：** ...

## 権限マトリクス
```

## DB 設計出力

```markdown
# データベース設計

## Prisma Schema
（完全な schema.prisma の内容）

## テーブル定義書
### テーブル名：xxx
| カラム名 | 型 | 説明 |

## シードデータの提案
## マイグレーション順序
```

## タスク分解出力

```markdown
# Phase X タスク分解

## タスク 1：（名称）
- 目的：
- 手順：
- 成果物：
- 受け入れ：
- Cursor 指示：
```

## Code Review 出力

```markdown
# Code Review 結果

## 合格項目
- ...

## 問題項目
| 深刻度 | ファイル | 問題 | 提案 |
|--------|------|------|------|

## まとめ
- マージ可 / 修正後にマージ
```
