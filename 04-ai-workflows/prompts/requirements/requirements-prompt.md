# AI プロンプト：要件ドキュメント生成

## 使用場面

口頭説明、議事録、またはプロジェクト立ち上げ情報から、構造化した要件ドキュメントの初稿を生成します。

## 入力（使用前に記入）

```
プロジェクト名：
プロジェクト目的：
主な利用者：
主要機能（リスト）：
既存システムとの関係：
技術的制約：
多人協業の方式：
```

## プロンプト

```
ai-engineering-playbook/05-templates/requirements-template.md の構造を参照し、
以下の情報から要件ドキュメントの完全な初稿（Markdown 形式）を生成してください。

【プロジェクト情報】
（上記の入力内容を貼り付ける）

【要求】
1. 各機能モジュールに必ず含める：機能説明、ユーザー役割、操作フロー
2. データモデルには主要テーブルと主要フィールドをすべて列挙
3. 開発フェーズは依存関係で分割し、各フェーズの前提条件と根拠（評価基準）を明記
4. 既存コードがある場合は、移行/維持/廃棄の方針を説明
5. OA 連携がある場合は、入口方式と役割マッピングを説明
6. 未決事項と、人の確認が必要な点を明示

【出力形式】
requirements-template.md の章構成を厳守して出力してください。
章の省略は禁止。内容がない章は「未定」と書き、理由も説明してください。
```

## 出力受け入れ

`04-ai-workflows/acceptance-checklists/requirements-checklist.md` で確認してください。

## 次のステップ

1. 人の review（漏れや誤りの修正）
2. 確認後、基本設計フェーズへ進む
