# AI プロンプト：開発タスク分解

## 使用場面

1 つの Phase を、段階的に実行できる小タスクへ分解します（Cursor Agent が順番に実行するため）。

## 入力（使用前に記入）

```
Phase 番号：
Phase 内容：（要件ドキュメントからコピー）
前提 Phase の完了内容：
技術スタック：Next.js + Prisma + PostgreSQL
```

## プロンプト

```
以下の Phase を 5〜10 個の「独立して実行できる小タスク」に分解してください。
各タスクは 30 分〜2 時間で完了できる粒度にしてください。

【Phase 内容】
（Phase の説明を貼り付け）

【完了済みの前提作業】
（前提 Phase の成果物を貼り付け）

【分解要件】
1. 各タスクには：目的、具体的な手順、成果物ファイル、受け入れ基準を含める
2. タスク間に明確な先後関係を付ける
3. 先にバックエンド/API、次にフロントページ
4. DB 変更タスクは最初に配置する
5. 各タスクに「そのまま Cursor Agent に貼り付けて実行できる指示文」を含める

【出力形式】
### タスク 1：（名称）
- 目的：
- 手順：
  1. ...
  2. ...
- 成果物：
- 受け入れ：
- Cursor 指示：
```
（上記の指示文をそのまま Cursor Agent に渡して実行）
```

## 次のステップ

タスク順に Cursor Agent へ逐次依頼し、各ステップ完了後に検証してから次へ進めてください。
